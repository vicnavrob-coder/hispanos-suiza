#### OPCIÓN B: Manual en Facebook Developers

1. Ve a: https://developers.facebook.com/tools/explorer/
2. Selecciona app "HispanosEnSuiza"
3. Get User Access Token → Selecciona permisos arriba
4. Copia el token
5. Guárdalo en `.env.local`:
```env

INSTAGRAM_ACCESS_TOKEN=<token>
```
