## 🔧 Implementación Técnica

### Stack:
1. **Autenticación**: NextAuth.js (Google + Email)
2. **Base de datos**: GitHub Gist (actual) + Stripe para suscripciones
3. **Stripe**: Producto de 2,99 CHF/mes recurrente
4. **Guards**: Middleware para verificar premium
5. **UI**: Modales de upgrade bien diseñados

### Flujo:
```
Usuario visita herramienta
  ↓
¿Registrado? → No → Modal registro
  ↓ Sí
¿Premium? → No → Versión básica + CTA upgrade
  ↓ Sí
Versión completa premium
```
